Report a wrong restroom listing

Fastest path: fix it yourself. Any listing in the app can be edited by anyone — open the restroom, tap to edit, and correct the name, hours, accessibility, gender-neutral status, or whether it costs money. The correction is live immediately and helps everyone behind you.

If a listing should be removed entirely, or you cannot edit it, use the bug report link below.

Bugs, feature requests, and everything else

Open an issue on the project repository:
github.com/oscar-leung/restroom-finder/issues

This is the best channel for bug reports, accessibility problems, feature ideas, data questions, press enquiries, and privacy requests. Issues are public, so do not post personal information in them.

Accessibility

Accessibility problems are treated as bugs, not feature requests. If something in the app is unusable with a screen reader, at larger text sizes, or with limited mobility, report it and it gets priority.

Privacy requests

Gotta Go has no accounts and stores no personal profile, so there is usually nothing to export or delete on our side — see the privacy policy for exactly what is and is not collected. If you still have a request, use the issues link above.

About the project

More on why this exists and where the data comes from is on the about page. The full source code is public at github.com/oscar-leung/restroom-finder.
